# Ellegance sounds

Interface sounds in the spirit of a premium console: struck glass for the
moments that matter (opening, a game starting, a notice, the boot), a small
glass note for every cursor step, a rounded pop to confirm and a soft
"tock" for switches. One file per event, as in `docs/temas.md`.

Origin: synthesized from scratch by `generate.py` (inharmonic glass partials,
pitched pops and filtered noise; mono, 44.1 kHz, Ogg Vorbis). No recording
or third-party material is involved; they are released under the same
license as the launcher (GPL-2.0-or-later).

To change them, edit `generate.py` and run it again (Python 3 and ffmpeg
with libvorbis).
