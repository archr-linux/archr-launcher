# Perfil de CPU

Exemplo de módulo `oneshot` do archr-launcher em sh + jq: item no menu Y de um
jogo que sugere o governador de CPU do sistema, e uma página em Configurações
com as escolhas e o governador atual. Na API 1 a sugestão só é mostrada; a
segunda fase traz `launch.before` para aplicá-la sozinha (veja `docs/modulos.md`).
